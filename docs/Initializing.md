# How to start?

# Main dev branch -> `origin/dev`

## 1. Pull from dev branch

`git checkout -b dev`  
`git pull origin dev`

## 2. Add `.env` files into:

### ALL ENV YOU CAN FIND IN OUR CHAT.

### `.env` into `/project` (root folder)

### `.env` into `/project/frontend/react-web`

### `.env` into `/project/frontend/react-web`

## 3. Add notifications `.json` into the folders:

### `firebase-credentials.json` to `project/backend/services/Notifications/internal/config`

### `google-services.json` to `project/frontend/react-native-mobile/`

## 4. Docker

### Root folder, command for startup:

### `docker compose up --build`
